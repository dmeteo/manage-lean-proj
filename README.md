# Lean Project Management

Учебное веб-приложение для управления lean-проектами предприятий и работы Регионального центра компетенций (РЦК). Цель — вести проекты, мероприятия, сроки, документы и согласования в одном месте, снижая повторный ввод сведений.

**Состояние на 26.11.2026:** подготовлен проект документации v0.1 для ревью. Код приложения, стенд, тесты и интеграции пока не созданы. Архитектура и API не утверждены. Документация не означает готовность функциональности.

## Источники и статус требований

Изучены расшифровка встречи «ПП пример запись lean.txt», рабочее ТЗ от 23.11.2026 «ТЗ_разработчикам_Lean_проекты_конкретные_требования.pdf», «Критерии для контрольных точек.docx» и контекст управления проектом. Оригиналы, персональные данные и внутренние материалы здесь не публикуются.

Заказчик подтвердил существование проектов, сроков, документов, последовательной проверки РП → старший РП → ФЦК, ручного Excel-расчёта эффекта и проблемы повторного ввода. Конкретные FR-01–FR-12, роли и поля взяты из рабочего ТЗ и требуют согласования. Предлагаемые технические решения в документации не являются утверждёнными требованиями заказчика. Федеральный портал остаётся обязательным; MVP его не заменяет.

## Команда

| Участник | Ответственность |
|---|---|
| Frontend-разработчик | Интерфейсы, MSW, тестирование, интеграция |
| Backend-разработчик | БД, API, авторизация, хранение файлов, развёртывание |
| Тимлид-аналитик | Требования, заказчик, приёмка, документация и защита |

Имена и контакты в публичном репозитории не размещаются.

## Структура

- `frontend/` — место клиентской части; пока только .gitkeep.
- `backend/` — место серверной части; пока только .gitkeep.
- `docs/` — техническая документация.
- `.gitignore` — исключения для секретов, сборок и локальных данных.
