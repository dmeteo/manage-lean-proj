# Lean Project · frontend

Требуется Node.js 24 LTS. При разработке использовались npm 11 и Node.js 24.

```sh
npm ci
npm run dev:demo
```

Откройте http://127.0.0.1:5174. Для локального прогона MSW используйте логин `m.volkova` и пароль `LeanProject2026!`. Это синтетическая учётная запись. Данные и признак сессии принадлежат локальному режиму.

```sh
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run dev` на порту 5173 и обычная сборка обращаются к `/api`. При интеграции потребуется настроить маршрутизацию API и отдачу `index.html` для маршрутов интерфейса. MSW запускается только в локальном режиме `dev:demo`.

Маршруты и сессия находятся в `src/app/`, страницы в `src/pages/`, HTTP-клиент в `src/api/`, ответы для разработки в `src/mocks/`.

Дашборд показывает общие счётчики API и нагрузку по датам из сводки. «Проекты» используют отдельный реестр с поиском и пагинацией. В карточке проекта открыт полный план с плановыми и фактическими датами, в карточке мероприятия — сведения, список документов и история проверки. Эти экраны предназначены для просмотра. Раздел «Мероприятия» фильтрует межпроектную сводку. Полный список по одному проекту открывается в его плане.
